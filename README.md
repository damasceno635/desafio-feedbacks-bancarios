# Desafio Criativo — Análise de Feedbacks Bancários com IA

## 📌 Sobre a atividade
Este repositório contém a entrega do **Desafio Criativo da DIO**, cujo objetivo é construir um prompt de IA capaz de analisar feedbacks de clientes bancários.

## 🎯 Objetivo
Criar um prompt claro, com intenção, contexto e restrições, para que a IA identifique:
- Temas recorrentes
- Sentimento dos clientes
- Urgência
- Oportunidades de melhoria

## 🧱 Etapas do desafio
1. **Definir a intenção** — o que a IA deve produzir, para quem e com qual finalidade.
2. **Adicionar contexto e restrições** — dados disponíveis, critérios de análise e cuidados.
3. **Unir as peças e refinar** — montar o prompt final.

## 📄 Arquivo principal
- `desafio-feedbacks-bancarios.md` — contém o passo a passo e o prompt final.

## 🚀 Como usar
Copie o prompt final e utilize em uma ferramenta de IA que aceite análise de texto. Em seguida, forneça os dados de feedback conforme descrito no prompt.

## ⚠️ Cuidados
- Use apenas os dados fornecidos.
- Não invente números, causas ou conclusões.
- Não exponha dados pessoais ou sensíveis.
- Informe limitações quando os dados não forem suficientes.
